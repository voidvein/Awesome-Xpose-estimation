先把“姿态”拆成可比较的任务

研究任务常见输入 → 输出读论文时重点核对
2D 关键点定位图像 / 视频 → 像素坐标与置信度关键点定义、检测框来源、遮挡与可见性；COCO AP / OKS 与 PCK 不应混为一个排名。
3D 姿态 / liftingRGB、深度或 2D 关键点 → 三维关节根节点相对坐标还是绝对坐标；是否使用尺度、旋转对齐；MPJPE 与 PA-MPJPE 不能直接互换。
参数化网格重建图像 / 视频 → 姿态、形状与网格人体、手部模型的版本与许可；关节误差与表面误差分别报告；预测相机不等于恢复真实尺度。
头部旋转 / 6DoF脸部图像或关键点 → 旋转，或旋转 + 平移Euler 角顺序、坐标系与角度范围；平移估计额外依赖相机和尺度条件。
视频与世界坐标运动时序观测 → 连续姿态与全局轨迹相机运动、可见帧范围、时间平滑与漂移；单帧误差之外还要检查时序质量。

三条阅读路线

这些是学习入口，不是性能排行榜。经典工作用来建立任务与表示的理解，新近方法用来追踪建模趋势。

从论文到实验：最小核对清单

  1. 锁定任务。 明确输入模态、研究对象和输出坐标系，不把人脸关键点、头姿和人体网格混在一个表里。
  2. 固定评测条件。 记录数据集划分、输入分辨率、检测器、相机标定、对齐协议与外部训练数据。
  3. 跑通官方基线。 检查模型、数据集和权重许可，记录依赖版本与 checkpoint 来源，再保存可复现命令。
  4. 验证而非只看数字。 分别检查遮挡、极端姿态、运动模糊和出画情况，记录速度测试的硬件、batch size 与预处理。
