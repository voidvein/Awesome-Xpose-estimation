A NOTE ON THE COLLECTION

一个可追溯的起点，
而非完整的排行榜。

按研究对象、输出维度与发表状态组织。Head 涵盖头部姿态与面部关键点；Hand 涵盖手部关键点及三维手部重建；Human 涵盖人体关键点、姿态与网格重建。

正式发表论文与 arXiv 预印本分别标注，预印本不等于已经同行评审。不同数据集、评估协议和输入条件下的结果不直接排名。每个条目链接至可核验来源。

覆盖时间与逐条来源请以论文数据和 README 为准。精选目录不声称穷尽所有工作，也不将收录视为质量背书。
